## Deskripsi
Program ini merupakan implementasi Algoritma Genetika (Genetic Algorithm) untuk menyelesaikan masalah penjadwalan mata kuliah.

## Spesifikasi Program
- Jumlah Mata Kuliah: 24
- Jumlah Dosen: 6
- Jumlah Ruang: 4
- Jumlah Slot Waktu: 12
- Populasi: 60 individu
- Generasi: 100
- Crossover Rate: 85%
- Mutation Rate: 20%

## Fitur Program
- Membuat populasi awal secara acak.
- Menghitung nilai fitness berdasarkan jumlah konflik jadwal.
- Melakukan proses seleksi, crossover, dan mutasi.
- Menampilkan jadwal terbaik.
- Menampilkan fitness terbaik dan jumlah konflik.
- Menampilkan grafik perkembangan fitness maksimum dan rata-rata.

## Hasil
Program berhasil menghasilkan jadwal terbaik dengan:
- Fitness Terbaik: **100**
- Jumlah Konflik: **0**
